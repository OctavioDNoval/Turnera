# Turnera — Frontend

SPA en React + Vite (JavaScript) del sistema Turnera (turnos para clases de guitarra).

- Requisitos, arquitectura y estado: ver [`AGENTS.md`](../AGENTS.md).
- Dev local: `npm install && npm run dev` → `http://localhost:5173` (proxy `/api` → `:8080`).
- En Docker se sirve con Nginx (ver `Dockerfile` y `nginx.conf`).
